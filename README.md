## 👨‍💻 About Me

I'm **Muhammad Ahsan**, a frontend developer from Pakistan who cares about how software *feels*, not just how it works. I like building polished, accessible, performant interfaces and shipping side projects that solve real problems.

- 🎯 **Focus:** modern frontend, TypeScript-first apps, and clean UI/UX
- 🛠️ **Currently building:** [Flowlyra](https://github.com/ahn009/Flowlyra), [scriptforge](https://github.com/ahn009/scriptforge), and [kindercode](https://github.com/ahn009/kindercode)
- 🌱 **Always learning:** system design, performance optimization, and AI-powered developer tools
- 🤝 **Open to:** collaborations, freelance work, and open-source contributions
- 💬 **Ask me about:** React, TypeScript, UI engineering, and shipping projects fast
